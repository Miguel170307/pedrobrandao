# PedroBrandao

Site de Pedro Brandão (Brands), professor de tênis de mesa.

## Estado atual

Base inicial com página de apresentação em desenvolvimento. Fotos, contatos, horários e modalidades de aula serão confirmados antes de entrar no site.

## Referências aprovadas

- [Motirõ](https://www.motiro.pro/)
- [PingPod](https://pingpod.com/)

As referências orientam a experiência e a organização. A identidade e o conteúdo do projeto serão próprios.

## Estrutura

- `index.html`: conteúdo da página.
- `css/style.css`: identidade visual e responsividade.
- `vercel.json`: configuração de publicação estática.

## Desenvolvimento

Abra `index.html` no navegador ou execute `python3 -m http.server 8000` na pasta do projeto.

Sem dependências e sem etapa de compilação. Atualizações da branch `main` serão publicadas pela integração com a Vercel.
