# Pedro Brandão — Brands

Site de apresentação do Brands, com aulas e trajetória no tênis de mesa.

## Organização

- `index.html`: conteúdo e estrutura.
- `css/style.css`: estilos e responsividade.
- `js/script.js`: interação do contato.
- `assets/`: cinco fotos e vídeo.
- `vercel.json`: configuração da hospedagem.

Abra `index.html` em um navegador ou utilize um servidor estático. Não precisa instalar dependências.

O contato é demonstrativo até recebermos o WhatsApp e os detalhes das aulas.
